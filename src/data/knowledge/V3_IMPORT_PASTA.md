# Import pasta SOOLLAR (manual)

Fluxo seguro para dumps offline — **não** varrer `temp/` antigo.

## Uso

1. Salve as páginas do portal SOOLLAR (HTML) numa pasta (por CD/seção).
2. Em **Preços por CD** → **Importar pasta (HTML)…** → escolha a pasta.
3. Conferir tabela → **Publicar no Supabase**.

Nomes de arquivo devem indicar o CD: `aeroporto`, `goiania`/`matriz`, `feira`.
